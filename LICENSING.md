# Licensing — Agentic AI Security Hackathon 2026

## Org default: Apache License 2.0

All public repos in [`agentic-ai-security-biu-2026`](https://github.com/agentic-ai-security-biu-2026) use **[Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0)** (`LICENSE` at repo root; SPDX: `Apache-2.0`).

**Why Apache-2.0 (not MIT / GPL):**

- Explicit **patent grant** — useful for security tooling and agent infra students may upstream later
- Compatible with **Red Hat** / CNCF-style open source norms
- Permissive for industry reuse without copyleft friction on student portfolios
- Clear attribution / NOTICE conventions if partners contribute branded samples

## What this covers

| Asset | License |
|-------|---------|
| `hackathon-hub` (docs, Pages landing, issue templates) | Apache-2.0 |
| Challenge stubs (`starter-ch*`) | Apache-2.0 |
| Team submission repos (`team-*`) at judging | **Apache-2.0 required** unless organizers approve another OSI license in writing before the deadline |

## Student submissions

1. Keep a `LICENSE` file (Apache-2.0) in the public `team-<slug>` repo at `submission-v1`.
2. Do not include proprietary third-party code you cannot relicense.
3. Dependencies may use other OSI licenses; document them in `NOTICE` or the README if required by those licenses.
4. Synthetic lab credentials only — never real secrets in licensed trees.

## Exceptions

Grad/paper track write-ups may stay under a separate academic copyright; **code and configs** submitted for judging still follow the table above.
