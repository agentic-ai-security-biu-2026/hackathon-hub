# Agentic AI Security Hackathon 2026

**Kickoff:** Sunday **13 December 2026**, Bar-Ilan University  
**Submission deadline:** **22 December 2026, 23:59** (public repo + `submission-v1`)  
**Closing:** week after deadline · Red Hat offices, Raanana  

Partners: **Red Hat** + **Nebius** · **Bar-Ilan Faculty of Computer Science** · Amplifiers: **UNIC**, **Bridge to Industry**, Bar-Ilan **Cyber Club**  
Teams: **3–6** · Mode: mostly remote after kickoff

## Share link (landing)

- Invitation (HTML + [`.md`](docs/invitation-en.md))

## Start here

1. Read and agree to the [**Code of Conduct**](CODE_OF_CONDUCT.md)
2. English invitation: [docs/invitation-en.md](docs/invitation-en.md) (or the [Pages invitation](https://agentic-ai-security-biu-2026.github.io/hackathon-hub/invitation.html))
3. Register (Form 1 / Form 2 links — published when Forms go live)
4. Pick a challenge from the stub repos below (open set freezes by registration volume; default aim **Ch1, Ch5, Ch7** + optional **Track 0**)
